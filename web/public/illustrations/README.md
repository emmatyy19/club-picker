# Caddie illustrations

Generated using the built-in image generation tool, October 2026. Decorative
assets with empty alt text. The ball-peeking bunny supplies the app logo.

- bunny-scorecard.png: cream bunny in a sage visor studying a scorecard.
- bunny-ball.png: cream bunny in a sage visor peeking over a golf ball.

Prompt direction: polished minimal pastel stationery illustration, rounded
shapes, forest-green outlines, cream, sage and blush, pink downward triangle
nose, transparent background, no text. Scorecard pose includes simple dots
and lines; ball pose uses sparse dimples. Unsuccessful glowing variants are
not shipped.

- bunny-club.png: matching bunny holding the grip of a golf iron with its head
  resting beside its feet. Generated on ivory to avoid the earlier glow artifact.
- ../app-icon-512.png: ball-peeking bunny on an opaque sage square; resized to
  192 and 180 pixels for manifest and Apple touch icons. Used in the header too.

Final prompts: preserve the ball bunny's identity and create a full-body pose
with a grip at chest level, long silver shaft, metal iron head on the ground,
solid ivory background and no glow. For the app icon, preserve the ball-peeking
pose on an edge-to-edge sage square, no text or baked-in rounded border. Both
were generated using the built-in image tool. PNG sizes use routine resizing.

The picker now uses bunny-club-cutout.png beside the page title. The built-in
image tool removed the ivory background while preserving the pose, colors and
iron, with the prompt: remove only the background and limb/shaft gaps, use true
alpha transparency, preserve the subject, add no shadow or glow. The earlier
opaque version is retained as the source reference.

- bunny-shots.png: a matching full-body bunny with a scatter-plot scorecard and
  pencil, generated with the built-in image tool for the My Shots header. It
  shares the picker bunny's 120px desktop / 92px phone display box.

Prompt: use the club-holding bunny as an identity/style reference; preserve the
cream body, sage visor, forest outlines, blush ears and pink downward-triangle
nose. Create a standing pose studying a small scorecard with five sage scatter
dots and a pencil. Include ears and feet, use true alpha transparency, and add
no text, backdrop, floor shadow or glow.
